# Insurance Neural Network Project

This project builds and trains a neural network using Keras to predict medical insurance charges based on personal characteristics.

## Goal
Predict individual medical insurance costs (`charges`) using:
- age
- sex
- bmi
- children
- smoker
- region

## Tools
- Python
- Pandas
- Scikit-learn
- TensorFlow / Keras
- Matplotlib
- Jupyter Notebook

## Project Structure
- `notebooks/` — project notebook
- `src/` — optional helper scripts
- `requirements.txt` — project dependencies
